# MZ Collections Inc.

A premium corporate-style Chicago, Illinois pet-products trading and ecommerce website built with Vite, React, TypeScript, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal. A production build can be checked with `npm run build`.

Product and lifestyle imagery currently uses remote Unsplash image URLs as provisional visual assets. Replace product images with approved matching manufacturer or retailer imagery before production use.
